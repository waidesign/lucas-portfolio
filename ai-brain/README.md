# AI Brain — Portfolio Project

This folder contains structured context, rules, and skills to help AI assistants work effectively on this codebase.

## Structure

```
ai-brain/
├── skills/               # Specialized capability guides
│   ├── README.md
│   ├── code-generation.md
│   ├── code-review.md
│   ├── debugging.md
│   ├── project-examples.md
│   └── seo.md
```

## Purpose

- **context.md** — What this project is and how it is built
- **identity.md** — Who Wai Phyo Aung is, brand voice, and design philosophy
- **playbook.md** — Step-by-step approach for common tasks
- **project-history.md** — Record of major changes for continuity across sessions
- **rules.md** — Non-negotiable constraints the AI must always respect
- **skills/** — Focused reference guides for specific technical tasks
